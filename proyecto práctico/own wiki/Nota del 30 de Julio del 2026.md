# Progreso
---
Para empezar a crear esta aplicación, quiero hacer un caso muy especifico, que sería el mio, como prototipo de lo necesario y lo importante

Para lograrlo, estoy creando una forma de importar mis datos de este obsidian, y creando una base de datos en [[SQLite|SQLite]], y también una [[Terminal User Interface (TUI)|TUI]] para mostrar y editar esa información, con la intención de definir como mostrar la información y que aspectos sería interesante construir, para crear una [[Página estatica|página estática]] donde representarlo
