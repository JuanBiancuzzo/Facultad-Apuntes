3. Una aplicación que consulta periódicamente las cotizaciones de [[Bitcoin|Bitcoin]] en cientos de exchanges y brokers ^parte-3
4. Una aplicación que subtitula para videos, convirtiendo voz a texto con una [[investigación/machine Learning/Red Neuronal/Red neuronal|red neuronal]] ^parte-4
