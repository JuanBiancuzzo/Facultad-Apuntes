# Enunciado
---
Un [[Robot RPR|robot RPR]] como el que se muestra a continuación, parte de reposo en la posición $\theta_1 = \begin{bmatrix} 90 & 0 & -90 \end{bmatrix}^T$ con [[Movimiento Joint|movimiento Joint]] hacia $\theta_2 = \begin{bmatrix} 0 & l & 0 \end{bmatrix}^T$ y sin detenerse vuelve a $\theta_1$, donde termina en reposo

![[colección/ejercicios/img/Robot RPR.png|500]]

Las velocidades máximas de cada eje son
* $v_{1,~ \text{max}} = 2 ~ \frac{\text{rad}}{\text{s}}$
* $v_{2,~ \text{max}} = 1 ~ \frac{\text{m}}{\text{s}}$
* $v_{2,~ \text{max}} = 2 ~ \frac{\text{rad}}{\text{s}}$

El tiempo de aceleración es $t_{acc} = 200 ~ \text{ms}$ y los movimientos se realizan a velocidad máxima

Se pide
1. Indicar los eslabones ^parte-1
2. Completar las ternas en la figura ^parte-2
3. Obtener los [[ingeniería electrónica/robótica industrial/Cinemática y estática/Cinemática#Asignación de ternas|parámetros DH]] ^parte-3
4. Graficar las curvas de posición, velocidad y aceleración en función del tiempo para cada eje para el movimiento solicitado ^parte-4
