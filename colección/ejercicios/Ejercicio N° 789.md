	u_{tt}(x,~ t) = u_{xx}(x,~ t) && x > 0, & t > 0 \\
	\displaystyle u(x, 0) = \frac{x}{x^4 + 3x^2 + 2} && x \ge 0 \\
	u_t(x, 0) = 0 && x \ge 0 \\
	u(0, t) = 0 && t \ge 0 \\
\end{cases} $$
