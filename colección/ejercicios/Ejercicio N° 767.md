# Enunciado
---
Una estación de carga de vehículos eléctricos opera bajo las siguientes reglas
1. Hasta $2$ vehículos pueden cargarse simultáneamente en la estación
2. Si la estación ha completado $4$ cargas seguidas (es decir, $4$ procesos de carga finalizados), un técnico debe realizar un mantenimiento preventivo antes de permitir nuevas cargas
3. El mantenimiento sólo puede realizarse si ningún vehículo está cargado en la estación
4. Las acciones de "iniciar carga", "finalizar carga" y "realizar mantenimiento" son atómicas

Se debe realizar
1. Modelar este sistema con una [[Red de Petri|red de Petri]], incluyendo ^parte-1
	* Lugares (con marcas iniciales). Explicar claramente el significado de cada uno de los lugares
	* Transiciones y arcos (usar arcos inhibidores si es necesario)
	* Anotaciones claras (ej: "Iniciar carga", "Realizar mantenimiento")
2. Mostrar un grafo de alcance sobre una posible ejecución ^parte-2
3. Explicar cómo el modelo desarrollado garantiza que el mantenimiento solo se realiza cuando no hay vehículos cargado ^parte-3
