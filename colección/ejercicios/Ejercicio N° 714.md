# Enunciado
---
Describa y justifique con que [[ingeniería en informática/sisop/Concurrencia/Concurrencia#Modelos|modelo de concurrencia]] modelaría la implementación para cada uno de los siguientes casos de uso
1. Convertir un conjunto extenso de archivos de DOC a [[ingeniería en informática/proba/Variables y vectores aleatorios/Función de densidad de probabilidad|PDF]] ^parte-1
2. El backend para una aplicación de preguntas y respuestas competitiva al estilo Menti o Kahoot ^parte-2
3. Una memoria cache utilizada para reducir la cantidad de requests en un [[ingeniería en informática/redes/Redes de computadoras/Servidor|servidor web]] a una [[ingeniería en informática/bdd/General/Base de datos|base de datos]] ^parte-3
4. Una [[ingeniería en informática/redes/Redes de computadoras/Aplicación Programming Interface|API]] [[ingeniería en informática/redes/Capa de aplicación/Hypertext Transfer Protocol|HTTP]] que ejecuta un modelo de [[investigación/machine Learning/Natural Language Processing/Natural Language Processing|procesamiento de lenguaje natural]] para [[ingeniería electrónica/taller de señales/Clasificación en Inteligencia Artificial/Clasificador|clasificar]] el sentimiento de un mensaje ^parte-4
