# Enunciado

Verdadero o falso justificando
1. En [[ingeniería electrónica/taller de comunicaciones/Modulación Analógica/Doble Banda Lateral - Portadora Fuerte|DBL-PF]] se puede usar detector de envolvente o detección coherente con un [[ingeniería electrónica/taller de comunicaciones/Modulación digital/Phase Locked Loop|PLL]], pero generalmente se suele usar detector de envolvente al ser más sencillo y económico ^parte-1
2. En BLV el ancho de banda necesario es la mitad que en una modulación DBL ^parte-2
3. En un una comunicación [[ingeniería electrónica/taller de comunicaciones/Modulación Analógica/Doble Banda Lateral - Portadora Suprimida|DBL-PS]] se debe realizar la sincronización del receptor con el transmisor, que puede ser realizada con un PLL ^parte-3
4. Dado un PLL de primer orden, se puede hacer que el error de fase y el ancho de banda del PLL sea arbitrariamente pequeño ^parte-$
