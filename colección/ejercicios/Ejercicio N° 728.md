# Enunciado

Para el [[ingeniería electrónica/robótica industrial/Cinemática y estática/Robot collaborative Z-ARM 2140C|robot collaborative Z-ARM 2140C]], se desea realizar un [[Movimiento Joint|movimiento joint]] según el siguiente recorrido para el segundo eje
* Parte de reposo en $0\degree$
* Se mueve a máxima velocidad deteniéndose al llegar a $60\degree$
Si la velocidad máxima del eje es $v_{2,~\text{amx}} = 120\degree \frac{1}{\text{seg}}$, y el tiempo de aceleracción es de $t_{acc} = 200 ~ \text{ms}$ hacer un gráfico completo de 
* La curva de posición en función del tiempo
* La curva de velocidad
* La curva de aceleración
