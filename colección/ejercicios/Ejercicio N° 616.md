# Enunciado
---
Marcar como Verdadero o Falso cada una de las siguientes afirmaciones
1. La suposición de [[Cadena de Markov|Markov]] implica que el estado actual del sistema contiene toda la información relevante para predecir el estado futuro, sin necesidad de conocer la historia completa del sistema ^punto-1
2. Un [[Robot holonómico|robot es holonómico]] si tiene más [[colección/componentes/actuadores/Actuadores|actuadores]] que [[investigación/animation/Grado de libertad|grados de libertad]] ^punto-2
3. El modelo de campos de [[ingeniería en informática/proba/Inferencia estadística/Función de verosimilitud|verosimilitud]] puede obtenerse a partir de un mapa de grillas de ocupación ^punto-3
4. El [[Muestreo estocástico universal (SUS)|muestreo estocástico universal (SUS)]] tiene una [[ingeniería en informática/algo 2/General/Complejidad computacional|complejidad computacional]] alta comparada con el muestreo aleatorio simple o de ruleta ^punto-4
5. Para obtener un mapa de grillas de ocupación, debe asumirse que la ocupación de una celda no depende de la ocupación de las celdas vecinas ^punto-5
